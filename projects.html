Regulated Power Supply for a Micromouse Robot

Designed and built a custom PCB power supply board for a micromouse robot. The board delivers regulated power to the rest of the system while reporting live battery level and charging status over I2C, so the rest of the robot's electronics can monitor power state in real time.
