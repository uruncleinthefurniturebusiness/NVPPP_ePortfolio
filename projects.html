U1 — Micromouse Power Supply Board

Regulated Power Supply for a Micromouse Robot

Co-designed (with a project partner) the power module of a 4-module Micro-Mouse robot, sharing one 80×62mm PCB against a $70 budget. The board regulates USB-C 9V (negotiated via a HUSB237 USB-PD controller) down to clean 3.3V/5V rails within 5% accuracy for the rest of the system, charges the Li-Po pack through a BQ24074 charger IC with switchable 200mA/600mA current, and reports live battery voltage and current back to the main processor over I2C via an INA219 sensor.

U3 — RISC-V Processor Core

RISC-V Processor with a CORDIC Hardware Accelerator

Designed a basic RISC-V-based processor core in Verilog, building out the datapath and instruction execution logic from the ground up, then extended it with a custom CORDIC Rotation Unit (CRU) wired in as a hardware accelerator for rotation/trig operations. Verified functional correctness by simulating the design in iVerilog, inspecting waveforms in GTKWave, and validating the CRU against golden test vectors generated in MATLAB.

Computer Architecture Verilog iVerilog GTKWave Hardware Accelerators

U4 — SIREN Buoy Power System

Cold-Climate Battery Power System for an Antarctic Sensing Buoy

Contributed the power subsystem to Project SIREN, a 4-person team design for a sensing buoy deployed in the Antarctic Marginal Ice Zone. Designed and implemented a battery-pack-conditioning circuit that self-heats the lithium-ion cells using thermistor feedback so they stay viable in extreme cold, built as STM32F103C8T6 firmware with supporting schematics, and backed by a literature review on cold-climate battery behaviour and LoRaWAN for the buoy's comms link.

U5 — Two-Antenna Radio Interferometer (in progress)

SDR-Based Radio Interferometer for UCT's 1420MHz Dishes

Final-year thesis project building a synchronised dual-channel SDR data-capture system across UCT Astronomy's two existing 1420MHz dish antennas, set on a 20m baseline. Uses a pair of ADALM-Pluto SDRs modified for synchronised sampling, feeding a Raspberry Pi for remote access, working towards cross-correlation image formation as a teaching demonstrator for radio astronomy courses.
